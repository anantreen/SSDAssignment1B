# Source vectors

`source-assets.json` contains SVG markup rendered from the existing shared `HouseArt.jsx` and the installed `lucide-react` icon components. The extractor keeps all four house palettes and the 21 icons used by the design scenes. Run `node docs/design/source-assets/prepare-assets.mjs` from the repository root after `npm ci` to refresh it.

The HouseArt vectors belong to this project's existing implementation. Lucide's notice is preserved in [LUCIDE-LICENSE.txt](LUCIDE-LICENSE.txt). SVG references retain the source paths; Excalidraw paths sample curves into editable vector lines.
