# Demo walkthrough (under five minutes)

A captioned walkthrough assembled from actual live seeded-browser captures is supplied as demo_walkthrough.mp4. Screenshots show tested behavior, not mock data. For a team-recorded presentation, use this sequence:

1. Browse paginated properties and open a detail; briefly switch to Guests and Bookings.
2. Select a demo guest and a property; attempt 365 nights to show insufficient funds.
3. Book one night with Check in now; point out wallet before/after and the trigger-created debit.
4. Try another check-in to show the partial unique-index error; complete the prior booking in Browse → Bookings.
5. Open Audit trail, filter by date and move between pages; explain saved running balances.
6. Open Analytics, show the seven-day lines and dense rank ties, then refresh the materialized totals.
7. Move the Search map origin; point out 5 km bounds, distance order and grid hotspots; add a pin and observe the results update.
8. Open Reviews, choose a property and show five rating buckets, tags, average, house rules and flexible nested amenities.
9. Briefly resize to phone width and show all six destinations; mention the recorded test and EXPLAIN logs.
